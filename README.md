# workflow

Tools from my personal Claude Code workflow, each in its own folder with its own README, install steps and tests.

| Tool | What it does |
|---|---|
| [`herdr-coordinator`](herdr-coordinator/) | Runs parallel Claude Code workers in [herdr](https://herdr.dev), one per GitHub issue. A coordinator session starts them, watches their transcripts, tells you only what needs you, and relays your answers. |

Everything here was built and is used on Windows 11 with Claude Code. Read each tool's README for its requirements before installing.
