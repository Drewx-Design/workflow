# Counting usage

[Usage note](2026-10-27.md).

The usage note applies three rules:

1. **Define the window and implementation.** Sorter activity starts at policy v6 adoption, excluding earlier development and rehearsal runs. Deployed tools can differ from the exported source snapshots.
2. **Count the outcome recorded.** Deduplicate sorter action IDs and require confirmation. Count intake-marked issues as usage. For cleanup, use final removal dispositions and keep deferred pruning separate. A proposed action is not a completed action.
3. **Keep the claim within the evidence.** Activity counts do not establish productivity gains or decision quality. Measuring those would require a baseline, operator intervention records, and a comparison on the same work.

Public notes contain aggregate counts. Private receipts retain the underlying file locators and hashes.
